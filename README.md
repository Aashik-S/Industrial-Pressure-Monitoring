# Industrial Pressure Monitoring

## Project Overview

This project focuses on developing a Python-based
industrial pressure monitoring system.

## Objectives

- Acquire pressure sensor data.
- Monitor real-time pressure values.
- Communicate with industrial controllers.
- Visualize pressure measurements.
- Store historical sensor data.

## Technologies

- Python
- Modbus RTU / TCP
- Industrial Pressure Sensors
- Data Visualization
